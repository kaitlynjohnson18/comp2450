this is a reserved keyword in c++
hidden pointer to current object instance within a class's non-static member functions
When we call a method on an object, c++ can auto pass the memory address of that object into a method as a 'this' pointer
Could use for resolving name conflicts (disambiguation)
Could return the current object (method chaining)
Could pass the object to an external function
